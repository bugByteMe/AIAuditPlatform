# 2026-11-06

## Responsive laptop and zoom layout

- Replaced the abrupt 980px desktop-to-stacked transition with desktop,
  compact-laptop, and narrow layout modes based on the effective CSS viewport.
- Compact laptops now retain a vertical icon rail and move secondary global
  actions into an overflow menu. Narrow screens use a short app bar instead of
  the previous oversized horizontal navigation block.
- Narrow chat session and file panels now open as overlay drawers. Their state
  is separate from the user's desktop fold state, so crossing a breakpoint does
  not overwrite the wider-layout preference.
- Added container-based chat-header and composer reflow, clamped medium-width
  panel sizing, accessible panel expansion state, and browser coverage for
  1024px and 760px viewports.

## Header and live-chat space

- Fixed wide-screen Codex settings visibility by separating direct desktop
  actions from the compact overflow menu instead of placing both behaviors in a
  closed `details` element.
- Removed the global workspace-creation header from the live-chat view and let
  the chat layout consume the released vertical space.
- Reduced the full desktop sidebar from 264px to 232px and the collapsed/compact
  icon rail from 76px to 64px, while retaining the narrow mobile app bar.
- Added browser assertions for the wide Codex action, thinner sidebar, compact
  overflow action, and hidden live-chat top bar. All 62 frontend unit tests pass;
  the browser suite could not run locally because Playwright is not installed.

## XLSX preview planning

- Added `docs/xlsx-preview.md`, a staged SheetJS integration plan covering local
  vendoring, worker-based parsing, authorized bounded delivery, safe DOM
  rendering, resource limits, failure states, and regression/security tests.
