# 2026-11-06

## Responsive laptop and zoom layout

- Replaced the abrupt 980px desktop-to-stacked transition with desktop,
  compact-laptop, and narrow layout modes based on the effective CSS viewport.
- Compact laptops now retain a vertical icon rail and move secondary global
  actions into an overflow menu. Narrow screens use a short app bar instead of
  the previous oversized horizontal navigation block.
- Narrow chat session and file panels now open as overlay drawers. Their state
  is separate from the user's desktop fold state, so crossing a breakpoint does
  not overwrite the wider-layout preference.
- Added container-based chat-header and composer reflow, clamped medium-width
  panel sizing, accessible panel expansion state, and browser coverage for
  1024px and 760px viewports.
