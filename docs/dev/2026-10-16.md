# Workspace upload controls and folder selection

- Exposed active append-upload identity and phase to authorized workspace owners and administrators, with batched catalog status lookups and pre-finalization cancellation from the card menu.
- Added an existing-folder destination picker for appended files and folders; the backend validates the target and prefixes paths before quota and collision checks. Browser resume records now include the destination.
- Added direct-child counts to lazy tree nodes and collapsed folders with more than five direct entries by default in both workspace trees.
- Added upload lifecycle, destination, tree threshold, and resume-fingerprint tests. Per deployment request, tests were not run locally.

## Office preview

- Disabled inline Office preview and direct PDF rendering on the control plane, including access to previously cached PDFs; Office files remain downloadable. The unsupported preview path skips full-file hashing. Added regression coverage; tests were not run locally.

## Chat workspace-file links

- Render agent Markdown links under `/workspace/` as file-download actions. A delegated click resolves the relative path through the selected workspace's authenticated raw-file endpoint, while unsafe paths and code blocks remain non-clickable. Added focused renderer tests.

## Preserve chats during upload cancellation

- Fixed append-upload lease creation, cancellation, and stale-lease repair to update only lock/upload columns. A lightweight workspace header carried an empty `sessions` list, so the previous lifecycle save deleted every workspace-session reference. Added tests for pre-existing and concurrently added chat references; tests were not run locally.
