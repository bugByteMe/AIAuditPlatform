# Development Notes - 2026-09-27

- Reorganized the Python backend into focused server, chat, workspace, upload,
  and account modules while preserving the existing HTTP, persistence, worker,
  and import contracts.
- Split the oversized chat-runtime and account-API test suites by behavior and
  added an automated 500-line maximum for all backend Python files.
- Kept the production ECS checkout untouched and validated the refactor in an
  isolated remote worktree.

- Fixed upload API URL construction when a persisted backend base URL ends in
  `/`; requests now target `/api/uploads` instead of the unmatched
  `//api/uploads` path that returned `404 {"error":"not_found"}`.
- Updated the Nginx upload location to cover both the upload-session collection
  endpoint and its child chunk/status endpoints with the same unbuffered,
  unlimited-body proxy settings.
- Added regression coverage for normalized browser upload URLs and deployment
  proxy matching.
- Reviewed the two preceding upload patches. Retained remote-worker result
  retrieval because the control plane cannot finalize from its local staging
  store when a compute worker owns the upload. Removed the blanket frontend
  retry for upload `404` responses: it masked route misses and could create an
  orphaned upload session, quota reservation, or append-workspace lock when a
  session disappeared after creation.
- Wired the chat event stream's top-scroll boundary to the existing backward
  event API so histories older than the latest page load on demand.
- Added a separate historical-event merge that preserves the forward live
  cursor, current session status, newer coalesced tool results, and visible
  scroll anchor when older rows are prepended.
- Added focused frontend regression coverage for the top threshold and
  historical page merging.
- Removed the full workspace-catalog reconstruction from workspace listing,
  workspace detail, chat session listing, chat event reconciliation, and SSE
  authorization reads. Added database-filtered workspace summaries and scoped
  single-workspace metadata loading for SQLite and PostgreSQL.
- Changed the browser to hydrate only the selected workspace detail. Workspace
  catalog rows no longer transport session, artifact, or file-tree collections.
- Replaced permanent two-second polling alongside SSE with server heartbeats,
  one connection-time cursor reconciliation, a 15-second stall watchdog,
  fallback polling, and exponential SSE reconnects.
- Added regression coverage for summary/detail separation, catalog-free event
  reads, terminal SSE heartbeats, and adaptive frontend stream wiring. Local
  tests were intentionally skipped; validation was run on the ECS host.
- Replaced whole-file checksum and preview reads with fixed-size streaming hash
  reads and bounded preview-prefix reads.
- Changed workspace ZIP delivery to build in a temporary bundle file and stream
  it with response-completion deletion plus one-hour stale-bundle cleanup.
- Moved remote-run final workspace scanning and blob creation to the compute
  worker. The control node now validates and records the returned manifest and
  never falls back to rehashing a remote workspace at terminal finalization.
- Updated focused workspace/runtime tests for bounded reads, disk-backed ZIPs,
  and manifest-based checkpointing. Per request, local tests were not run.
