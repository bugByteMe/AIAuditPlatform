# Development Notes - 2026-09-27

- Fixed upload API URL construction when a persisted backend base URL ends in
  `/`; requests now target `/api/uploads` instead of the unmatched
  `//api/uploads` path that returned `404 {"error":"not_found"}`.
- Updated the Nginx upload location to cover both the upload-session collection
  endpoint and its child chunk/status endpoints with the same unbuffered,
  unlimited-body proxy settings.
- Added regression coverage for normalized browser upload URLs and deployment
  proxy matching.
- Reviewed the two preceding upload patches. Retained remote-worker result
  retrieval because the control plane cannot finalize from its local staging
  store when a compute worker owns the upload. Removed the blanket frontend
  retry for upload `404` responses: it masked route misses and could create an
  orphaned upload session, quota reservation, or append-workspace lock when a
  session disappeared after creation.
- Wired the chat event stream's top-scroll boundary to the existing backward
  event API so histories older than the latest page load on demand.
- Added a separate historical-event merge that preserves the forward live
  cursor, current session status, newer coalesced tool results, and visible
  scroll anchor when older rows are prepended.
- Added focused frontend regression coverage for the top threshold and
  historical page merging.
