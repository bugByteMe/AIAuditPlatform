# 2026-10-09

## Workspace visibility and chat/recharge UI

- Platform administrators can list and open all workspaces and read private workspace chat sessions and events. Outside workspaces they own or share with their group, chat creation, updates, runs, stops, and forks remain unavailable; existing owner/system-admin mutation rules remain unchanged.
- Session summaries now expose and display the original `createdBy` username on each chat card, with a fallback for older records without that field.
- The chat model selector now offers `gpt-5.6-sol`, `gpt-6-astra`, `gpt-6-sol`, and `gpt-6.1-sol`. The selected high/medium reasoning effort remains recorded per run and written as `model_reasoning_effort` in its Codex configuration.
- Recharge choices now have a prominent remaining-budget percentage above them, refreshed from the current account session when the panel opens; custom-provider or unavailable balances use explanatory text.
- Added focused regression assertions for private workspace visibility, read-only admin access, session creator summaries, and Codex reasoning configuration.
