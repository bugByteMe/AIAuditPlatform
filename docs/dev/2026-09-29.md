# 2026-09-29

- Replaced runtime `accounts.json` persistence with normalized SQL rows for
  groups, users, invitations, recharge payments, and recharge orders. Common
  account/provider mutations now write only the affected row.
- Replaced the globally locked `upload_sessions.json` coordinator with indexed
  SQL session rows and upload-ID-scoped operation locks. PostgreSQL remains the
  production backend; isolated development uses SQLite fallback databases.
- Added offline, validation-first JSON import commands for account and upload
  coordination data. Production startup refuses populated legacy JSON state
  until it has been imported, and import leaves the source files unchanged.
- Added bounded upload garbage collection: abandoned sessions expire, worker
  reservations and append leases are released, failed staging deletion is
  retried, terminal rows age out, and workers independently remove stale upload
  staging without touching workspace or blob directories.
- Added regression coverage for SQL-backed coordination, terminal retention,
  stale-session expiration, and safe worker orphan cleanup. Tests were not run
  on the local machine as requested; verification is performed on ECS.
- Isolated synchronous file generation, upload forwarding, and external-provider
  calls in dedicated bounded executors. File-heavy work is limited to one
  control-plane thread on the current two-CPU ECS host, while overload returns a
  retryable `503` instead of exhausting the ordinary request/SSE thread pool.
- Added executor lifecycle, routing, cancellation, failure, and overload
  regression coverage. Validation continues in an isolated ECS worktree rather
  than against local or production storage.
- Added incremental run checkpoint protocol v2. Run admission persists a
  separate baseline, workers take a stat-only pre-run manifest, and completion
  hashes/copies only new or potentially changed files. Large result deltas are
  fetched separately and no longer inflate `runs.json`; legacy inline manifests
  remain accepted during rolling upgrades.
- Added nanosecond time, ctime, device, and inode fingerprints to current and
  previous file-version rows. Run completion now rebases and upserts only touched
  paths under a per-workspace lock. Blob reclamation is deferred for one hour and
  rechecks references before deletion.
- Added focused incremental-scan, path-scoped commit, and worker v2-result tests.
  Per request, the tests were written but not run on this local machine.
