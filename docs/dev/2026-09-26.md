# Development Notes - 2026-09-26

- Replaced whole-file `sessions.json`, `runs.json`, and transcript reads with a
  normalized SQL chat store supporting PostgreSQL production and SQLite tests.
- Added indexed, bounded forward/backward event cursors and stopped embedding
  full transcripts in workspace/session-list responses.
- Scoped chat admission locks by workspace/group/session/run, removed event
  reads and runner-event persistence from the workspace lifecycle lock, and
  reduced admission metadata persistence to the affected workspace lifecycle
  row and session references.
- Added a maintenance-cutover importer/validator for legacy JSON and JSONL chat
  state. Legacy sources remain untouched for rollback.
- Added PostgreSQL workspace metadata tables and selected them in production
  through the existing `AI_AUDIT_DATABASE_URL`; SQLite remains the local test
  fallback.
- Added a maintenance-mode SQLite-to-PostgreSQL workspace importer with
  empty-target protection and per-table count validation. Workspace payloads
  and content-addressed blobs remain on shared storage.
- Delayed publication of terminal chat session state until the corresponding
  workspace metadata and run records have committed, closing an observable
  completion-versus-persistence race found by remote regression testing.
