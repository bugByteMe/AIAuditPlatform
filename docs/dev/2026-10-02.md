# 2026-10-02：平台管理员与界面增强

## 权限与 API

新增 `platform_admin`，不改变现有用户分组模型和默认 `user` 角色。角色值继续存储在既有账号记录中，无需数据库迁移；创建及修改角色时校验四个合法角色，未知角色不获得管理权限。

| 能力 | system_admin | platform_admin | user / group_admin / 未知角色 |
| --- | --- | --- | --- |
| 查看用户、小组 | 允许 | 允许 | 拒绝 |
| 修改用户所属小组 | 允许 | 允许，仅 groupId | 拒绝 |
| 修改角色、状态及其他用户属性 | 允许 | 拒绝 | 拒绝 |
| 创建、删除小组 | 允许 | 允许 | 拒绝 |
| 修改小组名称、并发限制 | 允许 | 允许 | 拒绝 |
| 修改磁盘等其他小组配置 | 允许 | 拒绝 | 拒绝 |
| 预算、邀请、用户删除、审计日志、节点管理 | 保持现有权限 | 拒绝 | 保持现有非管理权限 |

服务端在操作前校验管理身份和字段白名单；混合提交允许与禁止字段时整体拒绝，返回 403，不先修改分组。角色变更保护最后一个系统管理员。用户更新先暂存验证，再更新既有内存账号及持久化记录。平台管理员列表使用公开账号序列化，不返回邀请令牌和系统管理员预算明细，不触发供应商余额刷新。

小组删除沿用现有级联删除成员及资源、停止运行、引用清理与保护管理员逻辑，没有改为迁移成员。

## 界面

系统管理员用户设置增加四种角色选择及中英文名称。平台管理员可访问用户、小组设置，仅提交 groupId 或 name/liveRunLimit；其他编辑控件隐藏并禁用。保存用户后刷新自身会话，及时应用自身角色变化。

聊天输入框保留原生垂直拖拽，最小 82px，最大为 320px 与 35dvh 的较小值。窄屏明确分配聊天行剩余高度，输入区不收缩；空间不足时聊天面板可滚动，保证拖拽角及发送控件可访问。未改变提交协议、消息内容或快捷键，也未增加高度持久化。

工作区概览标题使用真实小组名称显示“<小组名>的工作区”，管理员加载的小组最新名称优先；加载中、未分组及名称缺失时回退“工作区”。使用 textContent，支持英文。
