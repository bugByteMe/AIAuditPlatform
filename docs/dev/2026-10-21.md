# Standalone Keycloak deployment

- Added an optimized, version-pinned Keycloak image, independent PostgreSQL 17
  Compose deployment, private database network, loopback-only HTTP/management
  ports, health checks, and required externally configured credentials.
- Added a host-Nginx HTTPS example that overwrites forwarding headers, plus
  deployment, bootstrap, realm/customer attribute, backup, and upgrade guidance.
- Platform login, customer authorization, account migration, and Micu behavior
  remain unchanged. Added deployment-contract tests; Compose configuration
  validation and the diff whitespace check passed. No local container build or
  test run was performed.

## Shared OIDC identity implementation

- Added opt-in code/PKCE login, browser-bound state/nonce, issuer/audience/signature
  validation, Secure HttpOnly app cookies, refresh-token session revalidation,
  and explicit issuer/subject profile links with deleted-profile tombstones.
- Added customer directory and invitation customer controls, resumable identity
  provisioning, customer-scoped internal services, default-group admission,
  and protection against local shared-key/password/recharge mutations.
- Dedicated instances use their own Micu management credentials for direct
  balance checks; no balance proxy is shipped. Central provisioning/billing
  remain on main.
- Added offline, reviewed PBKDF2 hash migration preserving local ownership and
  Micu naming/bindings, with explicit customer and legacy-invitation mappings.
- Added CI regression tests and focused deployment/migration documentation.
  No local tests, container builds, or production migrations were performed.
- Python AST parsing, JavaScript syntax checks, and `git diff --check` passed.
  The largest changed source file is 900 lines; new identity modules are small.
