# Development Notes - 2026-09-28

- Replaced the online workspace compatibility-catalog save with scoped metadata
  commits for PostgreSQL and the SQLite test adapter.
- Workspace creation, file mutation, upload commit, fork, chat lifecycle, run
  finalization, recovery, and deletion now load and persist only the affected
  workspace. Quota reporting reads workspace summary rows rather than snapshot
  and artifact catalogs.
- Scoped commits lock the PostgreSQL workspace row, reject a stale snapshot
  parent, replace only that workspace's file-version and artifact rows, and
  check only candidate blob references during cleanup.
- Retained the full catalog loader as a read-only diagnostic and migration
  facility. Added regression coverage ensuring a workspace mutation neither
  loads the catalog nor changes an unrelated workspace.
- Replaced per-runner-event run/session saves with one atomic chat-store
  transaction covering event allocation, worker cursor, run/session state, and
  token usage. SSE wakeups now occur only after commit.
- Added idempotent remote-worker event receipts and database-backed cumulative
  user usage, eliminating duplicate replay charges and per-usage-event account
  JSON rewrites while preserving existing public event payloads.
