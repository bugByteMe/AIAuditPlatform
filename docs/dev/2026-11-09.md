# 2026-11-09

## Resilient upload finalization

- Added bounded prepared-file visibility retries for shared storage: 100 ms
  exponential backoff with a two-second deadline.
- Kept temporarily missing prepared files in `processing` so later status or
  garbage-collection reconciliation can complete them without dropping the
  workspace upload lease.
- Wrapped worker-result and workspace-commit failures, made successful
  post-commit cleanup best-effort, and ensured unexpected commit failures
  release append locks instead of leaving uploads indefinitely active.
- Extended upload garbage collection to reconcile stale `processing` and
  legacy `committing` sessions in addition to expiring abandoned transfers.
- Made workspace/snapshot publication and the upload session's terminal update
  one database transaction for both SQLite and PostgreSQL adapters.
- Added focused regressions for visibility retry, resumable temporary absence,
  unexpected commit failure, stale-session reconciliation, and transaction
  rollback when the upload coordination update fails.
