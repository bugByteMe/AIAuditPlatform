# 2026-10-08

## Upload inactivity and overload feedback

- Added `upload_session_idle_timeout_seconds` (default 300 seconds). A chunk request that stalls, or a session that receives no new chunk between requests, now expires after that interval, releases its compute reservation and append-workspace lock, and cleans its staging data.
- Kept resumable-session expiry based on successful client chunk activity. Upload status polling and worker reassignment no longer refresh the abandonment timestamp, and the upload collector runs no less frequently than the configured in-flight idle timeout.
- Added the saturated workload name (`file`, `upload`, or `external`) to `503 server_busy` responses. The browser converts these responses into localized, queue-specific notifications.
- Added focused regression tests for stalled request reads, terminal upload cleanup, status polling versus expiry, overload response metadata, and frontend workload messages.
- Prevented terminal upload sessions from reclaiming worker slots: chunk and completion requests now reject expired sessions before worker assignment, and expiry uses non-retryable HTTP 408.
- Fixed registration success handling by retaining the form element before awaiting the API response instead of reading the cleared asynchronous event `currentTarget`.
- Added lightweight workspace session counts, aggregate resource status for empty workspaces, explicit available-capacity labels, queued-job counts, and run-state-aware Send/Stop controls.
- Added a non-root control-plane Docker image with Python dependencies, LibreOffice/CJK preview support, persistent storage/config/certificate mounts, health checking, and documented build/run commands.
