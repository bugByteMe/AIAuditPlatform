# 2026-10-30

## Live chat workspace links

- Fixed new assistant messages whose workspace file destinations used
  `sandbox:/workspace/`, `file:///workspace/`, Markdown angle brackets, or safe
  unescaped spaces. These forms now normalize to the same authenticated
  workspace download action as historical `/workspace/` links.
- Kept normalization restricted to the `/workspace` root. Traversal, malformed
  encoding, backslashes, unrelated sandbox/file paths, and unsafe schemes remain
  non-clickable.

## Administrative workspace grouping

- Replaced the misleading administrator `<group>'s workspaces` heading with the
  generic workspace title and grouped the cross-group workspace list by the
  owning account's current group.
- The administrator's own group is the only section expanded initially. Manual
  expansion survives rerenders, while searches temporarily expand matching
  groups. Stored workspace group names provide a fallback until account data is

- Added group-aware search text, localized counts and ungrouped labels, compact
  group-section styling, and focused grouping/default-expansion tests.

## Admin search and workspace creation controls

- Added an administrator search field that filters whole group sections by a
  partial, case-insensitive group name or by any username in that group.
- Added empty workspace creation through `POST /api/workspaces`. Empty
  workspaces receive an initial empty snapshot; resumable upload sessions keep
  their existing requirement that at least one file is declared.
- Added a compact workspace-status refresh control that reloads the workspace
  list and refreshes the selected workspace details, with disabled/loading and
  localized completion states.
- Updated the new-workspace dialog and empty workspace-list copy to make file
  selection explicitly optional.

## Fine-grained workspace visibility

- Added private, selected-group-member, and whole-group workspace visibility.
  New workspaces default to private, while legacy shared workspaces migrate to
  whole-group visibility.
- Added stable account-ID grants, owner/admin access-management APIs, creation
  and management member pickers, visibility badges, and audit details for grant
  changes.
- Authorized selected and whole-group collaborators to upload and delete files
  as well as browse, download, chat, and fork. Workspace rename/deletion,
  access management, and exclusive run-lock changes remain owner/admin-only.
- Account group moves remove their grants; owner moves also reset owned
  workspaces to private and clear workspace grants. Account deletion/disable
  removes grants, and group renames propagate to workspace labels. Forks remain
  private and do not inherit grants.
- Prevented delayed run checkpoint writes from restoring stale visibility or
  group metadata after an access or membership change.
- Added focused backend access-control coverage and updated upload/frontend test
  fixtures. Tests were not run on this machine at the user's request.
