# Development notes - 2026-10-27

## Optional OIDC default admission group

- Allowed `AI_AUDIT_OIDC_DEFAULT_GROUP_ID` to remain unset in OIDC deployments.
- When unset, startup resolves the automatic admission group to the first-created
  existing group, using the group ID as a deterministic timestamp tie-breaker.
- OIDC startup still requires at least one local group.
- Configured default group IDs must still reference an existing local group.
- Added focused configuration and admission regression tests.
