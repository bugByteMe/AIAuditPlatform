# Development notes - 2026-10-24

## Universal seed identity reconciliation

- Reserved the `universal` identity customer for the two configured seed users.
- OIDC startup now restores missing seed profiles on non-empty installations,
  resolves their existing Keycloak subjects, ensures central Micu bindings, and
  atomically persists local issuer/subject links before the server becomes ready.
- Dedicated deployments accept their configured customer and `universal` users.
  Workspace ownership remains limited to those accepted scopes.
- Normal invitations, customer creation/reassignment, and local or central
  deletion cannot target universal seed identities.
- Added focused coverage for reconciliation idempotency, conflict handling,
  central binding reuse, dedicated admission, and workspace isolation.

## Chat focus layout

- Removed the grid columns previously reserved by collapsed session and file
  panels; their reopen controls now float over the chat edges.
- Added a reversible chat focus mode that collapses both side panels, hides the
  global navigation and toolbar, and restores the prior panel state on exit.
- Consolidated run state, token usage, diagnostics, and focus controls into a
  compact chat header. Runtime diagnostics open in an anchored popover.
- Kept assistant prose constrained to a readable line length while allowing
  command and preformatted technical output to use the available width.
- Added static and browser regression coverage for the new layout behavior.

## Lazy folded chat turns

- Changed paged chat history to return terminal turns as the user message plus
  the final assistant output (or final event), with other events represented by
  a count.
- Added authenticated lazy loading of a turn's omitted events when the user
  unfolds it; loaded details are cached for the current page session.
- Kept the latest active run outside turn compaction so all in-progress messages
  remain visible until the run reaches a terminal state.
- Preserved the authoritative event cursor across compact history loads so live
  SSE reconciliation skips persisted events that were intentionally omitted.
- Added session/type/cursor and session/run/cursor indexes for bounded turn-page
  and lazy-detail queries on existing and new databases.
- Added lifecycle, merge, and browser coverage for compact, expanded, and active
  turn behavior. Tests were added but not run locally at the user's request.
