# 2026-11-12

## Workspace symlink ownership

- Changed container workspace ownership preparation to set ownership on symlink
  entries without following their targets.
- Skipped permission-mode changes for symlinks so absolute, relative, and
  dangling workspace links cannot mutate files outside the workspace or block a
  chat run before its container starts.
- Added regression coverage for valid and dangling workspace symlinks.

## Codex MCP server configuration

- Added `mcp_server_config_path` and the `AI_AUDIT_MCP_SERVER_CONFIG_PATH`
  override for loading shared Codex MCP server definitions from JSON.
- Session-scoped Codex configuration now renders validated stdio and HTTP MCP
  server definitions into `config.toml` whenever a Codex home is prepared.
- Added an empty checked-in `config/mcp_servers.json`, configuration guidance,
  and regression coverage for valid and invalid MCP definitions.

## Per-chat capabilities

- Added a startup-validated capability catalog that maps localized user-facing
  choices to custom skills and MCP servers.
- Chat sessions now remember multi-capability selections, apply configured
  defaults to new and legacy chats, preserve explicit empty selections, and
  inherit valid selections across forks.
- Runs snapshot the resolved resource union, and control-node Codex-home
  preparation copies and renders only those selected resources before local or
  remote execution.
- Added the authenticated capability catalog API and a bilingual searchable
  multi-select picker beside collaborating workspaces in the chat composer.
- Added backend and frontend regression coverage for catalog validation,
  selection lifecycle, union deduplication, filtering, and localization. Tests
  were not executed locally at the user's request.
