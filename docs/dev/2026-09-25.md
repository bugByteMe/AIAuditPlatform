# Development Notes - 2026-09-25

- Replaced the browser-facing control-plane `ThreadingHTTPServer` transport with
  FastAPI and single-worker Uvicorn while preserving the existing API, cookie,
  static-file, command-line, and SSE contracts.
- Added asynchronous SSE wake-ups after persisted chat events so idle browser
  streams do not occupy one operating-system thread each.
- Added a bounded ASGI-to-blocking stream bridge for resumable upload chunks;
  chunk bodies continue to flow to local or remote workers without whole-body
  buffering.
- Kept the compute-worker agent server and existing workspace/chat persistence
  and locking model unchanged. Multi-process control-plane deployment remains
  unsupported until those states are moved to shared transactional storage.
- Prevented the local scheduler from launching a queued run after a concurrent
  stop request had already finalized it, matching the existing remote-worker
  admission check and removing a lifecycle teardown race.
- Added WeChat Pay Native recharge orders, signed API v3 calls, verified and
  decrypted callbacks, durable recovery state, and exactly-once reservation
  before MicuAPI balance updates.
- Replaced static QR payments with generated per-order QR images and live UI
  status polling; added a CNY 1 debug product that credits CNY 0.80.
- Added an Nginx HTTPS proxy template, secret-only WeChat configuration,
  reconciliation tests, and safe manual-review handling for uncertain credits.
