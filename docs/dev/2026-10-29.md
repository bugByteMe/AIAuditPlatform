# 2026-10-29

## Agent-created blocked-upload file types

- Separated generic workspace path normalization from blocked upload-extension
  validation. The generic normalizer was used by the compute worker's checkpoint
  scan, so a worker configured to block `.sh` rejected an agent-created shell
  script and returned `final workspace checkpoint unavailable`.
- Applied blocked-extension validation at legacy upload creation/appending,
  resumable upload admission, and worker-side upload initialization.
- Added regression coverage for executable shell-script checkpointing, ZIP
  download, generic path access, and upload admission.

## Download startup and binary streaming

- Marked attachment responses with identity content encoding so FastAPI's global
  gzip middleware does not recompress ZIP and other binary downloads.
- Added `X-Accel-Buffering: no` to file responses for immediate Nginx forwarding.
- Added a native-download acknowledgment handshake that shows “Preparing
  download” until the response starts, without loading the download into browser
  memory. Delayed or cross-origin handshakes fall back without blocking download.
- Added backend header/cookie coverage and frontend download-monitor tests.

## Chat session UX and rendering

- Centralized expired-login handling for JSON requests, upload XHRs, polling,
  and SSE failures. Runtime 401 responses now clear the credential, stop stream
  retries, show one localized explanation, and return to the login screen.
- Added the latest run's model and reasoning effort to public chat sessions.
  Entering a chat applies those settings once, while the backend inherits them
  when a client omits explicit settings.
- Added aligned Markdown tables and dependency-free native MathML rendering for
  common inline and display TeX syntax. Raw HTML remains escaped and malformed
  formulas fall back to visible code.
- Deferred chat-message attachments and download-compression offloading.
