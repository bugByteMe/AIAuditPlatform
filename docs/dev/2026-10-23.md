# Development notes - 2026-10-23

## Batched chat summaries and non-blocking workspace catalog

- Workspace detail and chat-session list responses now fetch all referenced chat
  sessions in one query and their latest runs in one query, rather than issuing
  per-chat lookups. Chat ordering and lightweight, history-free responses remain
  unchanged.
- Batch enrichment reuses the aggregate resource snapshot and caches each
  referenced worker status for the response.
- The browser now clears the workspace catalog loading state after the summary
  request completes. Selected-workspace detail continues in the background and
  updates the view when it arrives.
- Added regression coverage for batched session/run access and frontend loading
  order. Tests were not run locally, as requested.
