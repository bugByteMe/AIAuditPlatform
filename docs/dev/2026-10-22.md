# Development notes — 2026-10-22

## Public-customer OIDC migration mapping generator

- Added `backend/generate_oidc_mapping.py` to read existing SQL account tables
  using deployment database/storage configuration without AccountStore startup,
  schema creation, or account normalization. Default SQLite opens read-only.
- Generates public customer mappings for all local accounts and pending invites;
  retains existing public subjects and rejects non-public assignments, dedicated
  deployments, empty account datasets, and existing output paths.
- Output is exclusively created with mode 0600 and excludes passwords, hashes,
  invitation tokens, and Micu credentials. Logs include counts only.
- Added focused unit tests for selection, membership safeguards, subject
  preservation, private/no-overwrite output, and non-mutating SQLite reads.
- Updated the focused identity migration guide. No local tests were run, as
  requested; syntax and diff checks only.
