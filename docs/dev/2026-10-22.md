# Development notes — 2026-10-22

## Public-customer OIDC migration mapping generator

- Added `backend/generate_oidc_mapping.py` to read existing SQL account tables
  using deployment database/storage configuration without AccountStore startup,
  schema creation, or account normalization. Default SQLite opens read-only.
- Generates public customer mappings for all local accounts and pending invites;
  retains existing public subjects and rejects non-public assignments, dedicated
  deployments, empty account datasets, and existing output paths.
- Output is exclusively created with mode 0600 and excludes passwords, hashes,
  invitation tokens, and Micu credentials. Logs include counts only.
- Added focused unit tests for selection, membership safeguards, subject
  preservation, private/no-overwrite output, and non-mutating SQLite reads.
- Updated the focused identity migration guide. No local tests were run, as
  requested; syntax and diff checks only.

## Local readmission, full central deletion, and customer administration

- Account and group-cascade deletion now remove identity links within the account
  persistence transaction, allowing fresh ordinary-user admission after deletion.
- Added main-only full deletion with system-admin permission, explicit subject
  confirmation, existing self/last-admin protections, fail-closed disabling, and
  retryable Keycloak deletion. Other platforms' resources and Micu keys remain;
  retained central bindings reserve old usernames against key inheritance.
- Added main system/platform-admin customer reassignment for linked profiles;
  preserves other central attributes, local groups/roles, and Micu binding while
  invalidating main sessions. Dedicated operations remain forbidden.
- Moved customer controls below the invitation heading, localized their labels,
  and placed customer creation in a compact responsive disclosure. Added separate
  customer-change and full-delete confirmations to user settings.
- Added focused CI unit coverage for deletion/readmission, failure handling,
  central-operation boundaries, and customer preservation. Updated the operational
  guide with targeted stale-link cleanup. No local tests were executed.
